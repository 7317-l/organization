功能技术文书  |  版本 v2.0  |  2026年9月

一、系统概览

党建学习系统是一套面向基层党组织的数字化学习管理平台，采用前后端分离架构，为管理员提供党务管理、数据统计、AI分析能力，为党员提供在线学习、考试、组织生活、互动对战等功能。系统深度集成千问大模型，实现AI知识问答、个性化推荐、智能分析等智能化能力。

六、AI功能详解（15项智能化能力）

#功能实现方式技术要点
1AI党建知识问答RAG两级检索+千问生成BM25算法（TF+IDF+长度归一化，k1=1.5,b=0.75），一级召回20条+重排，返回引用来源
2错题K-Means聚类真正K-Means算法K-means++质心初始化、欧氏距离、迭代分配+更新质心、收敛判断，特征=[错误率,错误次数,答题次数]
3个性化学习推荐加权推荐算法薄弱标签从真实错题category动态生成，相似度用内容标签匹配度，非伪随机
4AI学习路线图三阶段规划+薄弱点筛选基础夯实→强化提升→冲刺巩固，内容按薄弱标签匹配度排序，每阶段3个KPI
5AI个人学习报告真实数据+千问总结从考试记录逐题判题计算真实错题率，千问生成总结建议
6NL2SQL自然语言查询双层安全过滤禁止SELECT *、危险关键字拦截、字段白名单、敏感字段脱敏、LIMIT≤100、多轮会话记忆
7AI数据脱敏全链路保护调用千问前对姓名/手机号脱敏（张*、138****xxxx），4处调用点全覆盖
8AI内容生成千问生成+审核入库支持题目/文章/宣讲稿/知识卡片，文件上传解析（pdf/docx），审核后一键入库
9AI组织生活总结签到+心得→AI简报千问生成简报，支持编辑/审核/归档/上报全流程，上报真实写库
10AI支部季度考核综合评级+整改闭环任务完成率/考试/活跃度/参与度→A/B/C/D评级，自动创建整改项
11党员发展AI辅助千问真正分析材料校验（千问分析非文件名规则）、思想汇报四维评分+改写建议、三类到期提醒
12AI学习预警4类异常检测连续低正确率/任务逾期/长期未学习/时长异常，真实防挂机数据，触发通知
13AI辅助互助匹配薄弱点智能推荐识别党员薄弱知识点，匹配优势党员结对
14AI学习标兵评选五维加权+千问评语学习时长/完成率/成绩/薄弱改进/积分，前5名千问生成个性化评语
15AI语音输入Web Speech APIwebkitSpeechRecognition，lang=zh-CN，interimResults实时显示，不支持时文本兜底

八、数据权限与安全机制

机制说明

# 1. 配置数据库连接
# 编辑 backend/appsettings.json，修改 ConnectionStrings.DefaultConnection

# 2. 配置千问API
# 在 backend/.env 中设置 DASHSCOPE_API_KEY=你的密钥

# 3. 启动后端（端口5091）
cd backend
dotnet run

# 4. 启动管理端（端口5173）
cd frontend/frontend-admin
npm install
npm run dev

# 5. 启动党员端（端口5174）
cd frontend/frontend-member
npm install
npm run dev
