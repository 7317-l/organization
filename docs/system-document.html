党校学习双端系统

管理后台 · 党员端 · 数据智能分析 · AI 能力
项目名称：party-school-system
后端：ASP.NET Core Web API（.NET 8）｜ 前端：Vue 3 + Vite + Element Plus
数据库：MySQL（party_school）｜ 文档日期：2026-09-01

一、项目概述

党校学习双端系统是一套面向基层党组织（党委—总支—支部三级架构）的数字化党建学习与管理系统，由管理后台与党员端两个前端应用及一个统一后端服务组成。系统覆盖组织人员管理、学习内容与任务、题库测验、三会一课组织生活、打卡签到与积分、消息通知、防挂机监督、多维度统计分析，并深度集成通义千问大模型 AI，提供党建智能问答、自然语言查数据（NL2SQL）、AI 错题专项巩固、AI 内容生成、AI 考核报告等能力。

面向用户

系统管理员 / 支部书记（管理后台）；正式党员 / 预备党员 / 积极分子（党员端）

核心目标

让党建学习有组织、有任务、有测验、有监督、有数据、有 AI 辅助，形成"学—测—评—改"闭环。

二、技术架构总览

层次技术选型说明
展示层Vue 3 + Vite + Element Plus + ECharts + Pinia + Vue Router + Axios管理后台（:5173）与党员端（:5174）两个独立 SPA，共用后端 API；ECharts 用于工作台/数据分析可视化。
接口/服务层ASP.NET Core Web API（.NET 8）、EF Core、JWT、AutoMapper、SwaggerRESTful 风格，路由统一 /api/v1；端口 5091；分层为 Controller → Service（接口+实现）→ Repository（DbContext）三层结构。
数据层MySQL 8（Pomelo.EntityFrameworkCore.MySql）数据库 party_school，26 张业务表，含 2 个 EF Migration（初始 + 扩展功能）。
智能服务通义千问（DashScope 兼容模式 · qwen-plus）统一封装 QwenService，支持文本对话与 JSON 结构化输出；密钥按 appsettings → 环境变量 → 仓库根 .env 三级解析。
辅助能力BCrypt 密码哈希 / ClosedXML + CsvHelper（题库批量导入）安全与效率配套。

系统总体架构（展示层 / 接口层 / 数据层 / 智能服务）见同目录 architecture.html 架构图。

八、关键设计与亮点

8.1 认证与权限

JWT Bearer 认证（AccessToken 120 分钟 + RefreshToken 7 天），密码 BCrypt 哈希；三类角色 系统管理员支部书记普通党员，通过 [Authorize(Roles=...)] 控制发布测验、删除等敏感操作。

8.2 组织架构统一口径（递归汇总）

新增 OrgHierarchyHelper 工具类，实现"组织 = 自身 + 全部子孙组织"的递归汇总。总支统计党员数/任务/成绩/完成率时自动包含其下所有支部，保证大屏排名、AI 各支部统计、支部考核报告、NL2SQL 四处口径一致，杜绝"第一党总支无数据"类问题。

8.3 防挂机监督

AntiCheatService 按"有效学习时长 / 总时长"计算有效率；AI 数据快照附带挂机监控（挂机人数、累计挂机分钟、原因分布：后台切换/长时间无动作/录屏黑屏/加速播放等），并支持"挂机原因 TOP5"自然语言查询。

8.4 AI 能力工程化

  • NL2SQL：规则意图优先（稳定）→ 千问兜底（复杂）→ 安全校验（仅 SELECT、危险关键字拦截、白名单表、自动 LIMIT）→ 真实只读执行 → 自动生成图表；前端折叠 SQL、中文列名展示。
  • 错题 KMeans：读取党员真实答题记录，按题目知识点聚合错误次数与严重度，输出薄弱标签与个性化练习建议（非随机占位）。
  • 数据智能分析：确定性意图识别（完成率/平均分/身份构成/趋势/时长/人数/挂机）+ 千问兜底，统一返回文本 + ECharts 图表数据。

8.5 健壮性

  • 全局异常中间件统一返回 { code, message } 结构；BusinessException 映射 4xx。
  • FlexibleDateTimeJsonConverter 兼容前端 "yyyy-MM-dd HH:mm:ss" 与 ISO 两种日期格式。
  • AutoMapper 统一实体 ↔ DTO 映射；EF 迁移管理表结构演进。

九、运行与部署

9.1 环境要求

  • Node.js ≥ 18（Vite 5）；.NET 8 SDK；MySQL 8（库名 party_school）
  • 千问 API Key：appsettings.json → 环境变量 DASHSCOPE_API_KEY → 仓库根 .env 三级配置

9.2 启动命令

# 后端（端口 5091） cd backend dotnet run --urls http://localhost:5091 # Swagger 文档：http://localhost:5091/swagger # 管理后台（端口 5173） cd frontend/frontend-admin npm install && npm run dev # 党员端（端口 5174） cd frontend/frontend-member npm install && npm run dev
